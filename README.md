# Higher Fire Community Calendar

Unofficial Google Calendars that turn the Higher Fire studios' kiln notes into calendar events: what's loading, firing, cooling and unloading at the Downtown and JTown studios, and when.

This is a community project by Gui Brunow. It isn't run by or affiliated with Higher Fire. Events are generated by AI from the studio's notes and may be wrong; the kiln notes are always the source of truth.

## How it works

A Google Apps Script reads the studio's kiln notes sheet several times an hour. New or edited notes go to Google's Gemini API, which splits each note into activities and picks out times ("unload by ~4pm"). The script then creates, updates or removes events in one Google Calendar per studio. Each event links back to the row of the sheet it came from.

## Subscribing

Each calendar's description has a "Share this calendar" link. On an iPhone or Mac, tap it to subscribe. In Google Calendar, add it under Other calendars → From URL.

## Privacy policy

The Google sign-in app "Higher Fire Community" exists only so the maintainer can deploy and run this script. Nobody else signs in to it.

The script:

- reads the studio's kiln notes sheet, which the studio shares with its members;
- sends the text of new or edited notes to Google's Gemini API to turn them into events. On Gemini's free tier, Google may use that text to improve its models;
- writes events to calendars owned by the maintainer's Google account.

It collects nothing else. Subscribing shares nothing about you with the maintainer: your calendar app only downloads the public feed.

Questions or removal requests: Gui Brunow, gbrunow@outlook.com.

## Development

The script is `src/Code.gs`; setup steps and settings are in the comment at its top. [clasp](https://github.com/google/clasp) deploys it:

    npx clasp login
    npm run push
