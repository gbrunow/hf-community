# Higher Fire Community Calendar

A Google Apps Script that turns the Higher Fire studio's shared notes into Google Calendar events: what's loading, firing, cooling and unloading in the kilns, when unclaimed work is discarded, when the studio is closed or has a workshop, and the class schedule. It covers the Downtown studio.

This is a community project by Gui Brunow. It isn't run by or affiliated with Higher Fire. Events are generated by AI from the studio's notes and may be wrong; the kiln notes are always the source of truth.

## Subscribing

The calendars and every way to subscribe to them are on [the calendar page](https://gbrunow.github.io/hf-community/).

## How it works

A Google Apps Script reads the studio's shared spreadsheet (the kiln notes, the discard schedule and the events list) several times an hour. New or edited rows go to Google's Gemini API, which splits them into events and picks out times ("unload by ~4pm"). The script then creates, updates or removes events in two Google Calendars: one for the studio's kiln notes, closures, workshops and discard days, and one for its class sessions. Each event links back to where it came from in the sheet.

The calendar page is `index.html` at the root of this repository, served by GitHub Pages. Its design rules are in `CLAUDE.md`.

## Development

The script lives in `src/`: setup steps are at the top of `src/main.js`, settings in `src/config.js`, and everything an event says (wording, layout, links, titles) in `src/content.js`. [clasp](https://github.com/google/clasp) deploys it:

    npm install
    npx clasp login
    npm run verify   # type-check, then run the tests
    npm run push
